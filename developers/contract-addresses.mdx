## Security Notes

- Never send funds directly to contract addresses
- Always verify addresses before interaction
- Use official interfaces and verified contracts only
- Report suspicious activity through our bug bounty program

## Updates

Contract addresses may be updated during protocol upgrades. Always check this page and our official channels for the latest addresses.
