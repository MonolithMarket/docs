# Lender Contract

The Lender contract implements the core lending functionality, managing deposits, borrows, liquidations, and redemptions.

<ParamField path="contracts/Lender.sol" type="string">
  The main lending pool implementation
</ParamField>

## User-Facing Functions

### adjust

```solidity
function adjust(address account, int collateralDelta, int debtDelta) external
```

Adjusts a user's position by modifying collateral and/or debt. This is the primary function for depositing, withdrawing, borrowing, and repaying.

**Parameters:**
- `account`: Address of the position to adjust
- `collateralDelta`: Amount to add (positive) or remove (negative) collateral (in wei)
- `debtDelta`: Amount to borrow (positive) or repay (negative) debt (in wei)

**Requirements:**
- If `collateralDelta > 0`: Account must approve collateral token transfer
- If `debtDelta > 0`: Account must have sufficient collateral ratio
- If `debtDelta < 0`: Account must have sufficient debt to repay
- Account must not be liquidatable after adjustment

**Behavior:**
- Automatically accrues interest before adjustment
- Updates collateral and debt positions
- Maintains minimum debt requirements
- Emits position update events

### liquidate

```solidity
function liquidate(address borrower, uint repayAmount, uint minCollateralOut) external returns (uint collateralOut)
```

Liquidates an undercollateralized position to maintain protocol solvency.

**Parameters:**
- `borrower`: Address of the position to liquidate
- `repayAmount`: Amount of debt to repay (in wei)
- `minCollateralOut`: Minimum collateral amount to receive (slippage protection)

**Returns:**
- `collateralOut`: Amount of collateral received by liquidator

**Requirements:**
- Borrower position must be liquidatable
- `repayAmount` must be ≤ maximum liquidatable debt
- `repayAmount` must be ≥ minimum liquidation amount
- Liquidator must have sufficient Coin balance

**Liquidation Process:**
1. Accrue interest on borrower's position
2. Verify liquidation conditions
3. Transfer Coin from liquidator to repay debt
4. Calculate collateral reward with incentive
5. Transfer collateral to liquidator
6. Update borrower's position

**Incentive Calculation:**
- Base incentive: 8% of repaid debt value
- Additional incentive for low collateral ratios
- Maximum incentive: 50%

### redeem

```solidity
function redeem(uint amountIn, uint minAmountOut) external returns (uint amountOut)
```

Redeems Coin for underlying collateral at current redemption price.

**Parameters:**
- `amountIn`: Amount of Coin to redeem (in wei)
- `minAmountOut`: Minimum collateral amount to receive (slippage protection)

**Returns:**
- `amountOut`: Amount of collateral received

**Requirements:**
- Redemption must be enabled for caller
- Sufficient collateral reserves available
- `amountOut` must be ≥ `minAmountOut`

**Redemption Price:**
- Calculated based on total debt vs total collateral
- Includes redemption fee (default 0.03%)
- Price adjusts dynamically with protocol health

### delegate

```solidity
function delegate(address delegatee, bool isDelegatee) external
```

Delegates or revokes delegation rights for position management.

**Parameters:**
- `delegatee`: Address to grant/revoke delegation
- `isDelegatee`: True to grant, false to revoke

**Requirements:**
- `delegatee` cannot be zero address
- Cannot delegate to self

**Effects:**
- Allows delegatee to call `adjust()` on behalf of delegator
- Delegation can be changed at any time

### setRedemptionStatus

```solidity
function setRedemptionStatus(address account, bool chooseRedeemable) external
```

Sets whether an account's collateral can be redeemed by others.

**Parameters:**
- `account`: Address to set redemption status for (can be any address)
- `chooseRedeemable`: True to allow redemption, false to prevent

**Requirements:**
- If `account != msg.sender`, must have delegation rights

**Effects:**
- Controls whether collateral can be seized during bad debt socialization
- Default is redeemable for new positions

### accrueInterest

```solidity
function accrueInterest() public
```

Accrues interest on all outstanding debt positions. Called automatically by state-changing functions.

**Effects:**
- Updates `lastAccrue` timestamp
- Increases total debt proportionally
- Updates interest rate based on utilization
- Accrues protocol reserves

---

### writeOff

```solidity
function writeOff(address borrower, address to) external returns (bool writtenOff)
```

Writes off unrecoverable debt and socializes losses across all borrowers.

**Parameters:**
- `borrower`: Address with bad debt position
- `to`: Address to receive written-off collateral

**Returns:**
- `writtenOff`: True if debt was written off

**Requirements:**
- Position must be underwater (debt > max recoverable value)
- Only callable by authorized addresses

**Effects:**
- Reduces total debt proportionally across all positions
- Transfers remaining collateral to specified address
- Maintains protocol solvency

## Key State Variables

### totalPaidDebt
Total amount of interest-bearing debt in the protocol.

### totalFreeDebt
Total amount of non-interest-bearing debt in the protocol.

### collateralFactor
Maximum collateralization ratio (e.g., 0.8e18 = 80%).

### minDebt
Minimum debt amount required for positions.

### immutabilityDeadline
Timestamp after which protocol becomes immutable.

### feeBps
Protocol fee rate in basis points.

### Redeem
Emitted when Coin is redeemed for collateral.

### AccrueInterest
Emitted when interest is accrued on debt.
