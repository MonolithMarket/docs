## Quick Start Paths

### I want to earn yield
1. [Buy stablecoins](/guides/buy-and-stake-stablecoins#acquiring-stablecoins) via PSM or DEX
2. [Stake in the Vault](/guides/buy-and-stake-stablecoins#staking-for-yield) to earn interest

### I want to borrow
1. [Deposit collateral](/guides/borrow-stablecoins#step-1-deposit-collateral)
2. [Choose paid or free debt](/guides/borrow-stablecoins#step-2-choose-your-debt-mode)
3. [Borrow stablecoins](/guides/borrow-stablecoins#step-3-borrow-stablecoins)

### I want to arbitrage
1. [Monitor stablecoin price](/guides/redeem-stablecoins#arbitrage-opportunity) vs $1
2. [Redeem when below peg](/guides/redeem-stablecoins#step-by-step-guide) for profit

### I want to run a liquidation bot
1. [Monitor positions](/guides/liquidate-positions#step-1-find-liquidatable-positions)
2. [Calculate profitability](/guides/liquidate-positions#step-2-calculate-profitability)
3. [Execute liquidations](/guides/liquidate-positions#step-3-execute-liquidation)

### I want to create a stablecoin
1. [Prepare parameters](/guides/deploy-stablecoin#step-2-configure-parameters)
2. [Deploy via Factory](/guides/deploy-stablecoin#step-3-deploy)
3. [Manage as operator](/guides/operate-stablecoin)
