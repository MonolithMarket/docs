## Overview

Monolith's smart contracts have been reviewed by independent security firms before and during deployment. The audit program covers both the core Monolith protocol contracts and the complementary Inverse Finance components that interact with it. All findings from completed engagements have been remediated prior to deployment. The ChainSecurity re-audit of the Monolith protocol is complete and its final report is pending publication.

<Note>
  Audit reports will be linked here upon public release. All completed engagements have been fully remediated — no outstanding findings remain unaddressed.
</Note>

## Audit Philosophy

Security reviews are a necessary but not sufficient condition for safe deployment. Each audit engagement is treated as a starting point rather than a finish line. Findings are triaged and addressed before contracts go live, and re-audits are commissioned whenever material changes are made to previously reviewed code. Beyond external audits, the protocol maintains an active bug bounty program and ongoing internal review processes.
